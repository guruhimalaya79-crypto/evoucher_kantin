# Sistem E-Voucher Kantin

Aplikasi internal kantor untuk mengelola e-voucher kantin dan transaksi makanan menggunakan mini POS sederhana.

## Teknologi

- Python
- Streamlit
- SQLite
- Pandas
- OpenPyXL
- bcrypt

## Fitur Utama

- Login admin, kasir, dan pegawai
- Hak akses berdasarkan role
- Master divisi
- Master pegawai
- Master kategori menu
- Master menu makanan
- Kasir Mini POS
- Keranjang item makanan
- Validasi saldo voucher
- Saldo pegawai
- Riwayat transaksi
- Void transaksi dengan alasan
- Dashboard laporan
- Laporan pembayaran pedagang
- Export Excel/CSV
- Backup database
